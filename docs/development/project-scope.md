# Project scope

Sculith targets a public production server engine that other operators can install, extend and maintain, comparable in role to Endstone or Dragonfly. Commercial use is part of that goal. The existing MIT license remains in place.

에스테리아 일대기 is the primary real-use and integration server. Its RPG rules, progression and content belong in Rust plugins and resource packs. Networking, world ownership, inventory, content conversion and the server API remain general engine features.

Production readiness includes usable client interactions, bounded plugin execution, authentication, storage/recovery, version compatibility, installation and updates. Current local development checks do not establish all of these properties. New work is accumulated toward 0.1.0; preview packages and GitHub binary artifacts remain withdrawn.
