# Rust gameplay plugin preview

Rust 게임 플러그인 예제를 동봉했습니다. 새 폴더에 ZIP을 풀고 `start.cmd`를 실행하면
별도 Rust 설치 없이 플러그인을 로드합니다. 접속자에게 개인 환영 메시지를 보내고,
실제로 승인된 블록 변경의 리비전을 로그에 기록합니다. 설정한 서버 이름은 유지합니다.

- 베드락: 같은 PC의 `127.0.0.1`, 포트 `19132`.
- Java **26.3**: 같은 PC의 `127.0.0.1:25565`.
- 플러그인: `plugins/sculith-gameplay-plugin.exe`, 새 설정의 `[[plugins]]`에 등록돼 있습니다.
- 기존 설정과 월드는 자동으로 바꾸지 않습니다. 이전 설정을 옮겼다면 예제 플러그인을 자동 추가하지 않습니다.

## 게임 API v2

- 초기화가 확인된 플레이어 접속/종료, 커밋된 블록 변경 훅과 `SendMessage`를 추가했습니다.
  에디션별 패킷 ID 대신 공통 플레이어 핸들·에디션·블록 이름을 제공합니다.
- 소유자가 메시지의 대상 세션·텍스트·호출량을 확인합니다. 플레이어별 초당 4개/순간 8개까지입니다.
  다른 플레이어에게 메시지가 섞이지 않으며, 메시지는 게임 훅으로 재귀 전달하지 않습니다.
- API v1 실행 파일을 그대로 지원하고 새 SDK는 v2를 자동 협상합니다.
  콜백 요청은 동시에 기다리되 액션은 설정 순서대로 적용합니다.
- 게임 알림을 놓친 구독자는 명시적으로 비활성화하고 기록합니다. 훅은 커밋 이후 알림이며 취소 훅이 아닙니다.

순정 Java 26.3을 직접 실행해 한국어·이모지 환영 메시지 표시를 확인했습니다.
처음 발견한 Java NBT 문자열 인코딩 오류를 수정했고, 독립 검사가 구형 바이너리에서 실패하고
수정본에서 통과하는 것도 확인했습니다.
[실제 게임 화면과 검증 기록](https://github.com/SKYRPG8957/Sculith/blob/main/docs/verification/2026-11-16-plugin-api-v2.md)

## 현재 범위

같은 PC의 명시적 오프라인 개발 프리뷰입니다. 실제 게임 표시는 Linux 순정 Java에서 확인했습니다.
공식 베드락 Windows GDK 앱과 Windows 게임 렌더링은 이 환경에서 실행하지 못했으며,
베드락 검증은 독립 프로토콜 클라이언트 결과입니다. 전체 호환성 메타데이터는 보수적으로 유지합니다.

플러그인은 신뢰된 실행 파일이며 WASI 샌드박스가 아닙니다. 명령·일반 월드/인벤토리 API,
취소 훅·스케줄러는 아직 없습니다. 공유 리소스팩 자동 전달·사운드·모델·폼과 다른 플레이어 표시는
계속 구현 중입니다. 서버 종료 정리는 `Stopping`을 사용하며 남은 `PlayerLeft` 콜백은 보장하지 않습니다.

English: Bundles a real Rust gameplay plugin with API-v1 compatibility and API-v2
join/leave/post-commit hooks plus owner-validated private system messages. Korean
and emoji rendering was checked in the unmodified Linux Java 26.3 game; independent
clients and native Windows release/plugin/packaging checks pass. Full content
compatibility, a WASI sandbox and official Windows Bedrock-game verification remain pending.
