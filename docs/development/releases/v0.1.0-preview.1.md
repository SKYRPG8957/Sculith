Windows x64에서 Sculith를 로컬 테스트하기 위한 개발 프리뷰입니다.

1. 아래 Assets의 `sculith-v0.1.0-preview.1-windows-x86_64.zip`을 받습니다.
2. ZIP 전체를 압축 해제하고 **start.cmd를 더블클릭**합니다. Rust·Python·Java 설치는 필요 없습니다.
3. 같은 PC의 Minecraft for Windows(Bedrock)에서 서버 **127.0.0.1**, 포트 **19132**를 추가합니다.
4. 종료할 때 서버 창에서 **Ctrl+C**를 누르면 최종 월드 스냅샷을 저장합니다.

설정은 `sculith.toml`, 월드는 `world/region.sculith`입니다. 기존 설정은 덮어쓰지 않습니다.
SHA-256 체크섬은 `SHA256SUMS.txt`, 빌드 commit과 플랫폼은 ZIP 안의 `release.json`에 기록되어 있습니다.
설치·연결 문제와 Windows UWP loopback 설정은 [Windows 빠른 시작](https://github.com/SKYRPG8957/Sculith/blob/main/docs/windows-quickstart.md)을 참고하세요.

**현재 범위:** Bedrock 1.26.60 / protocol 2225를 개발 참고값으로 사용합니다. 평지 스폰·제한된 크리에이티브 이동/건축은 헤드리스 프로토콜 클라이언트로 검증했습니다.
**공식 Minecraft 클라이언트의 실제 입장·렌더링은 아직 미검증입니다. Java 월드 접속은 미구현입니다.** 일반 인벤토리, 생존/중력, 다른 플레이어 표시와 완전한 팩 호환성도 개발 중입니다.

이 로컬 예제는 loopback에서 테스트 신원을 허용합니다. 공개 서버 운영용 설정이 아닙니다.
주기적 자동 저장은 아직 없으므로 창을 강제로 닫으면 시작 이후 변경이 유실될 수 있습니다.
