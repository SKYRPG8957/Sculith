# Actual-client-verified Java 26.3 wire fixes

순정 Java 26.3 클라이언트를 직접 실행해 Preview 8의 두 패킷 오류를 재현하고 수정했습니다.
Linux에서 실제 평지 표시, 키보드 이동, 마우스 설치·파괴·재설치, 정상 접속 종료,
서버 재시작 후 블록 보존과 재입장을 확인했습니다.

[실제 게임 화면·버전·검증 기록](https://github.com/SKYRPG8957/Sculith/blob/main/docs/verification/2026-11-16-java26.3.md)

## 수정 사항

- 이전 게임 모드를 구형 signed byte `-1` 대신 26.3의 OPTIONAL_VAR_INT로 인코딩합니다.
  기존 형식은 순정 게임에서 `clientbound/minecraft:login` 디코딩 오류를 일으켰습니다.
- 위치 확인 응답의 ID뿐 아니라 X/Y/Z와 yaw/pitch도 읽습니다. 클라이언트가 확인한
  값이 서버의 교정 값과 일치하고 유한한지 검증하며, 이를 새로운 이동 명령으로 쓰지 않습니다.
- 독립 Python 클라이언트와 실제 소켓 테스트도 최신 형식을 검사합니다.
  잘못된 위치 또는 NaN을 담은 확인 응답을 거부하는 검사도 통과했습니다.
- 베드락 초기화 전 Interact/33 알림 수정과 기존의 권위 입력·인증 경계는 유지합니다.

순정 Java와 같은 서버에 독립 베드락 NetherNet 클라이언트를 함께 연결했습니다.
베드락이 `(0,3,2)`를 부순 결과가 Java 화면에 나타났고, Java 마우스의
설치 → 파괴 → 재설치 결과를 베드락이 같은 좌표의 Air/Stone 변경으로 받았습니다.
모드, 프록시나 별도 Minecraft 서버 프로세스는 사용하지 않았습니다.

## 설치와 범위

기존 서버를 Ctrl+C로 종료하고 ZIP 전체를 새 폴더에 풀어 `start.cmd`를 실행하세요.
진단 로그는 `diagnose.cmd`입니다. 서버 실행에는 Rust·Python·Java 설치가 필요 없습니다.

- 같은 PC 베드락: 주소 `127.0.0.1`, 포트 `19132`.
- 같은 PC Java **26.3**: 서버 주소 `127.0.0.1:25565`.
- 이전 설정을 옮겼다면 Java가 자동 활성화되지는 않습니다. 예제의 `[java]` 항목을 확인하세요.
- 기존 월드는 서버가 종료된 상태에서 `world` 폴더 전체를 보존하세요. Ctrl+C로 정상 종료할 때 저장합니다.

**공식 베드락 Windows GDK 앱의 입장과 Windows 게임 렌더링은 아직 확인하지 못했습니다.**
베드락 결과는 독립 프로토콜 클라이언트 검사이며 위의 실제 게임 검증은 Linux Java에 한정됩니다.
이 환경에는 해당 Windows GDK 앱이 없으며 온라인 계정 인증도 검증하지 않았습니다.
패키지의 넓은 `official_client_verified: false` 표시는 전체 호환성을 보증하지 않는 상태로 유지합니다.

같은 PC의 명시적 오프라인 개발 경로입니다. 다른 플레이어 표시, 일반 인벤토리,
생존/중력, 주기적 저장, Java 온라인 인증, 공유 모델/사운드/UI와 팩 자동 배포는 아직 구현 중입니다.

English: Fixes two Java 26.3 layouts reproduced with the unmodified official game:
OPTIONAL_VAR_INT previous game mode and full teleport confirmation data. Actual
Linux entry/rendering, keyboard movement, mouse building, bidirectional changes
with an independent Bedrock client, UI disconnect and persisted restart/re-entry
were checked. Native Windows executable/installer checks are distinct from official
Windows Bedrock-game verification, which remains unavailable in this environment.
