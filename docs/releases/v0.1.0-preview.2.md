접속 진단을 보강한 Windows x64 개발 프리뷰입니다.

Windows GDK `1.26.63`에서 보고된 `Terracotta / InitialConnection-149`를 조사하기 위한 버전입니다.
**해당 접속 오류의 해결은 아직 확인하지 못했습니다. Java 월드 접속도 미구현입니다.**

1. 실행 중인 Sculith를 Ctrl+C로 종료합니다.
2. `sculith-v0.1.0-preview.2-windows-x86_64.zip`을 새 폴더에 전체 압축 해제합니다.
3. 접속 조사에는 `diagnose.cmd`, 일반 실행에는 `start.cmd`를 사용합니다.
4. 같은 PC의 베드락에서 `127.0.0.1:19132`로 접속을 다시 시도합니다.

설정과 월드를 이어 쓰려면 종료 후 기존 `sculith.toml`과 `world`를 새 폴더로 복사합니다.
진단 출력은 UDP 패킷 종류·크기, RakNet과 게임 프로토콜 번호, 실패 단계를 기록합니다.
게임 버전과 접속을 시도한 직후 추가된 로그로 원인을 좁힐 수 있습니다.
로그인 요청 원문이나 토큰을 공유할 필요는 없습니다.

독립적인 UDP 패킷 테스트로 초기 연결을 검증했고 서명·암호화·권한 검사는 유지했습니다.
공식 Minecraft 클라이언트의 입장·렌더링은 미검증입니다. Rust·Python·Java 설치는 필요 없습니다.
