# Bedrock pre-spawn interaction preview

Preview 6의 공식 Windows GDK 1.26.63 접속은 로그인 후 스폰 대기 중 packet_id=33을 거부했고, 서버가 연결을 종료하면서 InitialConnection-40을 표시했습니다.
33번 Interact는 포인터 대상/인벤토리 상태 알림입니다. 초기화 확인 전에는 게임 권한으로 사용하지 않고 버리도록 수정합니다.

- 실제 로그와 같은 알림을 보내 기존 실패를 재현한 뒤 수정 후 통과를 확인했습니다.
- RakNet과 NetherNet 테스트 모두 초기화 확인 전에 Interact 알림을 보내도록 보완했습니다.
- 로딩 중 부가 상태 패킷은 최대 4,096개와 기존 시간 제한 안에서 버립니다. 게임 행동을 대기열에 넣거나 월드 상태에 적용하지 않습니다.
- 로그인/네트워크 설정/암호화 절차 재시작과 너무 이른 초기화 확인은 계속 거부합니다.
- 기존 구조 데이터 순서, 바이옴/청크 전송, DTLS 키 검증과 서버 권위 입력 검사는 유지합니다.

기존 서버를 Ctrl+C로 종료하고 ZIP 전체를 새 폴더에 푼 뒤 diagnose.cmd를 실행하세요. 주소는 127.0.0.1, 포트는 19132입니다. 기존 데이터를 이어 쓰려면 종료 상태에서 sculith.toml과 world 폴더 전체를 복사하세요.

공식 게임에서 실제 평지 화면까지 들어가는지는 재접속 검증이 필요합니다. Java 월드 입장과 전체 게임/팩 호환성은 구현 중입니다.

English: Fixes the confirmed pre-initialization rejection of vanilla Interact/33 notifications, discards bounded ancillary loading status without applying game intent, and retains authentication/state-transition and owner checks. Official Minecraft entry remains awaiting a successful retest.
