# Shared sounds preview

베드락 원본 팩의 같은 OGG 음원을 순정 Java에도 전달하고 Rust 플러그인에서 재생합니다.
새 폴더의 `start.cmd`는 게임·메뉴·사운드 예제 3개를 로드합니다.
공통 텍스처와 메뉴를 사용하며, 초기화가 끝난 접속자에게 짧은 원본 안내음을 개인 재생합니다.
기존 설정·월드는 보존하고, 기존 설정에는 플러그인을 자동 추가하지 않습니다.

- 베드락: 같은 PC의 `127.0.0.1`, 포트 `19132`.
- 순정 Java **26.3**: `127.0.0.1:25565`. 클라이언트 모드가 필요 없습니다.
- 공통 팩 사용에 동의해야 합니다. 이번 버전은 등록된 단일 Vorbis 음원만 지원합니다.

## Rust API v4

`PlaySound { player_id, sound, volume, pitch }`를 추가했습니다.
소유자가 현재 접속·초기화, 등록된 음원, 유한한 음량 `0..1`·피치 `0.5..2`,
플레이어별 초당 4개/순간 4개 제한을 검사합니다. 위치는 소유자가 플레이어 눈 위치로 정합니다.
다른 접속자에게 보내거나 블록 리비전을 바꾸지 않고, 게임 훅으로 재진입하지 않습니다.
기존 v1·v2·v3 실행 파일을 지원합니다. 기존 게임 훅·폼의 최소 버전도 유지합니다.

매핑한 베드락 사운드 정의와 원본 OGG로 Java 이벤트를 생성합니다.
선택한 정의의 가중치·반복·스트리밍 등 지원하지 않는 의미를 조용히 버리지 않고 거부합니다.
최대 64개 이벤트, 단일 Vorbis 스트림, 원본 30초, 1~2채널, 8~48kHz 제한을 적용합니다.
원본 팩은 수정하지 않으며, 자산 변경 시 생성 팩의 캐시 ID도 바뀝니다.
공유 월드의 베드락 서버 목록에는 실제 Creative 상태가 표시되도록 수정했습니다.

## 검증

순정 Linux Java 26.3이 실제로 팩을 로드하고 월드에 입장해 원본 안내음을 재생했습니다.
클라이언트의 실제 48kHz 스테레오 PCM 출력에서 880Hz 피크와 해당 대역의 99.7221% 에너지를 확인했습니다.
스피커를 사람이 청취했다는 의미는 아닙니다. 독립 Python/Go 클라이언트는 양쪽 음원 바이트,
재생 패킷, 위치·음량·피치·반복 여부와 개인 수신자 분리를 검사했습니다.
Linux Clippy, 125개 프로젝트 테스트, 소유권 doctest와 실제 보관한 v1·v2·v3 실행 파일 검사가 통과했습니다.

[API·원본·제한](https://github.com/SKYRPG8957/Sculith/blob/main/docs/sounds.md),
[실제 게임과 검증 기록](https://github.com/SKYRPG8957/Sculith/blob/main/docs/verification/2026-11-16-shared-sound.md).

네이티브 Windows [run 43801768939](https://github.com/SKYRPG8957/Sculith/actions/runs/43801768939)에서
실행 파일·두 접속부·플러그인·폼·사운드·팩 캐시·패키징·실행기 검사도 통과했습니다.
정확한 소스는 `e3fe40318a496da96f22a7c9d0ce4b46cab5eaaa`입니다.
ZIP **6,269,330 bytes**, SHA-256
`9d2e071f60a204df58ee0e1be6a2800b3ad945e48e5e9e4609c415a66291a5f5`.
19개 파일, 소스 메타데이터, 라이선스와 네 EXE의 시스템 DLL 전용 구성을 확인했습니다.
개인 키, 월드, Minecraft JAR/게임 자산이나 테스트 클라이언트는 포함하지 않습니다.
[공개 배포 run 43802965625](https://github.com/SKYRPG8957/Sculith/actions/runs/43802965625) 이후
인증 없는 HTTPS로 ZIP과 체크섬을 새로 내려받아 소스·태그·SHA-256을 재검증했습니다.
설치기와 다운로드 기본값은 Preview 13이며, 네이티브 Windows 공개 설치 검증을 진행합니다.

## 현재 범위

공식 Windows 베드락 앱의 입장과 소리/화면 출력은 여전히 미확인입니다.
자동 검사의 베드락 클라이언트는 독립 구현이며 공식 앱의 성공을 대신하지 않습니다.
모델·애니메이션·임의의 JSON UI 변환, 다른 플레이어 표시와 일반 게임 기능은 계속 구현 중입니다.
Rust 플러그인은 신뢰된 실행 파일이며 WASI 샌드박스가 아닙니다.

English: Adds API-v4 private custom sound playback and matching native/Java pack
events from the same original OGG. Existing v1/v2/v3 executable plugins remain
compatible. The unmodified Linux Java game produced actual PCM with the authored
880-Hz tone; independent clients check native assets/packets and recipient isolation.
Official Windows Bedrock-game rendering/audio and general content compatibility
remain unverified.
