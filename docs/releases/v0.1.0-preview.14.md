# Shared static models preview

베드락 원본 팩의 정적 직육면체 모델을 순정 Java에서도 표시합니다.
새 폴더의 `start.cmd`는 게임·메뉴·사운드·모델 예제 4개를 로드합니다.
접속자 앞에 원본 체크무늬 장식 모델을 표시하며, 클라이언트 모드는 필요 없습니다.

- 베드락: 같은 PC의 `127.0.0.1`, 포트 `19132`.
- 순정 Java **26.3**: `127.0.0.1:25565`.
- 게임의 필수 팩 사용에 동의해야 합니다. 기존 설정·월드는 보존하고 플러그인을 자동 추가하지 않습니다.

## Rust API v5

`ShowModel { player_id, model }` / `HideModel { player_id }`를 추가했습니다.
플레이어별 개인 미리보기 하나를 표시·교체·숨깁니다. 소유자가 등록된 모델, 접속/초기화,
초당 1회 표시 제한, 위치와 지역 경계를 검사합니다. 위치는 플레이어 앞 3블록으로 정합니다.
표시는 월드 리비전이나 게임 훅을 바꾸지 않습니다. 충돌·상호작용·물리·AI·영구 저장은 제공하지 않습니다.
기존 v1·v2·v3·v4 실행 파일과 게임/폼/사운드의 최소 API 버전을 유지했습니다.

원본의 client entity·geometry·정적 컨트롤러·PNG를 베드락에 그대로 전달합니다.
Java에는 같은 텍스처의 Item Display 모델을 생성합니다. 회전 없는 뼈 1~64개, 직육면체 1~128개,
명시적 면 UV, 불투명 8비트 PNG만 지원합니다. 모델은 최대 32개입니다.
지원하지 않는 회전·애니메이션·재질·투명도와 잘못된 뼈/UV는 명시적으로 거부합니다.
변환 파일이 기존 텍스처 매핑을 덮어쓰는 경우도 거부합니다.

## 검증

정확한 소스 `1d46a8164cb27007daf45f89bb0afec5a015ada5`에서 순정 Linux Java가
원본 텍스처 모델을 표시하고 교체·숨김 이후에도 연결을 유지했습니다.
첫 실제 게임 검사에서 발견한 새 item atlas 경로 차이를 수정했습니다.
네 예제를 함께 켠 실제 게임에서도 모델, 메뉴 클릭/개인 메시지, 880Hz 사운드 PCM 출력을 확인했습니다.
독립 Python/Go 클라이언트는 두 팩·원본 자산·모델 생성/교체/숨김·수신자 분리를 검사했습니다.

Linux Clippy, 131개 프로젝트 테스트와 소유권 doctest, 실제 보관한 v1~v4 실행 파일 검사가 통과했습니다.

실행 파일·두 접속부·모델·기존 폼/사운드·팩 캐시·패키징·실행기 검사를 통과했습니다.

ZIP **6,526,986 bytes**, SHA-256
`d7809c89f6bba52d793d32ba9350cfdaba6fd4e7b37708e7fdd5bbe09961c2ff`.

## 현재 범위

개인 장식 미리보기이며 다른 플레이어 표시나 일반 엔티티 API는 아직 구현 중입니다.
비대칭 면의 방향·재질 전체 호환, 회전/애니메이션, 임의의 JSON UI 변환도 계속 구현 중입니다.
공식 Windows 베드락 앱의 실제 입장·렌더링은 미확인입니다. 독립 클라이언트의 성공은 별도로 표시합니다.
Rust 플러그인은 신뢰된 실행 파일이며 WASI 샌드박스가 아닙니다.

English: Adds API-v5 private static model previews from one authored Bedrock
geometry/texture source. Stock Java Item Displays support the explicit unrotated
cuboid subset. Actual Java shows the textured model, replacement/hide and all four
bundled examples together. Independent clients and native Windows release checks
pass. Older v1–v4 workers remain compatible. Official Windows Bedrock-game rendering,
animated models and general entities remain unverified or unimplemented.
