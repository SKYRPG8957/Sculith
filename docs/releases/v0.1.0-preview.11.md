# Shared texture pack preview

한 베드락 원본 팩을 접속 시 두 에디션에 자동 전달합니다.
새 폴더에 ZIP을 풀고 `start.cmd`를 실행하면 Rust 플러그인과 원본 체크무늬 예제가 함께 활성화됩니다.
게임에서 팩 사용 동의가 나타나면 계속을 선택하면 됩니다. Stone에 체크무늬가 표시됩니다.

- 베드락: 같은 PC의 `127.0.0.1`, 포트 `19132`.
- Java **26.3**: 같은 PC의 `127.0.0.1:25565`. 모드·프록시·별도 Java 서버는 필요 없습니다.
- 원본 팩: `packs/sculith-demo`, 대응표: `packs/sculith-demo-textures.json`.
- 기존 설정·월드·키 파일은 보존합니다. 이전 설정에는 팩이나 플러그인을 자동 추가하지 않습니다.

서버는 시작 시 원본과 대응표를 고정해 양쪽 팩을 생성합니다. 콘텐츠가 바뀌면 캐시 식별자도 바뀝니다.
자바는 해시가 붙은 로컬 HTTP 경로로 변환 팩을 받고, 베드락은 청크 전송 또는 기존 캐시를 사용합니다.
필수 팩의 거부·잘못된 식별자·잘못된 순서·다운로드/리로드 실패는 월드 입장 전에 거부합니다.
팩 동의·리로드 대기 중에도 자바 연결을 유지합니다.

순정 Linux Java 26.3을 직접 실행해 캐시를 비운 상태에서 다운로드·적용·체크무늬 표시를 확인했습니다.
네이티브 Windows [run 43789669645](https://github.com/SKYRPG8957/Sculith/actions/runs/43789669645)도 통과했습니다.
[설정·한계·실제 화면·독립 검사](https://github.com/SKYRPG8957/Sculith/blob/main/docs/content-delivery.md).

Linux는 114개 프로젝트 테스트, 소유권 doctest, Clippy와 기존 실행 파일 검사를 통과했습니다.
독립 ZIP/CRC/해시 검사, Java 필수 팩 다운로드, 베드락 다중 청크 전송·캐시 재접속을 확인했습니다.
40초간 동의를 보류하고 완료 응답 뒤 연결 유지 응답을 보내는 검사와 부정 협상 검사도 포함합니다.

## 현재 범위

명시적으로 대응시킨 정적 PNG 텍스처와 같은 PC의 개발 세션을 대상으로 합니다.
단일 resources 팩만 받으며 종속 팩·하위 팩·스크립트·행동 모듈은 지원하지 않습니다.
각 ZIP은 최대 32 MiB이며 파일·경로·전송·로그인·HTTP 연결량에 제한을 적용합니다.
이 서버는 Java 없이 실행합니다. Java 런타임은 Java 게임을 실행하는 PC에만 필요합니다.

공식 Windows 베드락 앱의 입장/렌더링은 아직 미확인입니다. 베드락은 독립 프로토콜 클라이언트로 검증합니다.
온라인 Java 인증, 일반 인벤토리·생존/중력·다른 플레이어 표시, 사운드·모델·폼과 일반 UI 변환,
공개 콘텐츠 호스팅·핫 리로드는 계속 구현 중입니다. Rust 플러그인은 신뢰된 실행 파일이며 샌드박스가 아닙니다.

English: Automatically delivers one authored Bedrock resource pack and its mapped
Java texture conversion. The unmodified Linux Java 26.3 game downloaded and
rendered the pack. Independent clients test archive integrity, required-pack
states, native chunk delivery/cache and consent keepalive. This is a local
development preview; broad content compatibility and official Windows Bedrock
rendering remain unverified.
