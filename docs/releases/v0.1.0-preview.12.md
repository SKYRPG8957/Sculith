# Shared forms preview

Rust 플러그인에서 같은 메뉴를 베드락과 순정 Java에 표시하고, 선택·취소 결과를 받을 수 있습니다.
새 폴더의 `start.cmd`는 기존 게임 예제와 `plugins/sculith-forms-plugin.exe`를 함께 로드합니다.
입장 후 안내 메뉴에서 버튼을 선택하면 해당 플레이어에게 플러그인의 개인 안내 메시지를 보냅니다.

- 베드락: 같은 PC의 `127.0.0.1`, 포트 `19132`. 기본 메뉴 폼을 사용합니다.
- Java **26.3**: `127.0.0.1:25565`. 순정 대화상자를 사용하며 클라이언트 모드는 필요 없습니다.
- 기존 공유 텍스처팩과 저장된 월드를 유지합니다. 기존 설정에는 플러그인을 자동 추가하지 않습니다.

## Rust API v3

`ShowForm { player_id, request_id, form }`과 `FormSubmitted`를 추가했습니다.
이벤트는 폼을 연 해당 플러그인만 받습니다. `selection`은 선택지 인덱스 또는 취소 `None`입니다.
제목·버튼은 128 UTF-8 바이트, 본문은 2,048 바이트, 선택지는 1~8개로 제한합니다.
소유자가 접속/초기화·한 개의 대기 폼·초당 한 개의 요청·60초 응답 기한·선택 범위·중복 응답을 검사합니다.
플러그인의 요청 키와 내부 전송 ID는 분리합니다. 폼은 블록 리비전을 바꾸지 않습니다.

기존 v1·v2 실행 파일을 지원하고, 새 SDK도 구형 호스트와 공통으로 지원하는 가장 높은 버전을 선택합니다.
기존 게임 훅의 최소 버전은 계속 v2입니다. 폼은 v3가 없는 호스트에서 명시적으로 거부합니다.

## 검증

순정 Linux Java 26.3에서 한국어·이모지 메뉴가 표시됐고, 실제 마우스 클릭이 소유 플러그인에 도달해
개인 안내 메시지를 표시했습니다. 독립 Java NBT 판독기와 Go/Pion 베드락 클라이언트로 같은 메뉴의
선택·취소·다른 세션 응답 위조·중복 응답·수신자/소유 플러그인 분리를 검사했습니다.
별도의 구독 플러그인은 다른 플러그인의 응답을 받지 않습니다.

Linux Clippy, 120개 프로젝트 테스트와 소유권 doctest를 통과했습니다.
보관한 실제 v1·v2 Rust 실행 파일과 기존 게임·접속·플러그인 검사도 통과했습니다.
네이티브 Windows [run 43795929884](https://github.com/SKYRPG8957/Sculith/actions/runs/43795929884)에서도
빌드·실행·폼·팩·플러그인·패키징·실행기 검사를 모두 통과했습니다.
[사용 방법·한계·실제 화면](https://github.com/SKYRPG8957/Sculith/blob/main/docs/forms.md).

## 현재 범위

공통 단순 선택 폼이며, 임의의 베드락 JSON UI·HUD·이미지·입력 창을 자동 변환하는 기능은 아닙니다.
응답이 없으면 폼은 대기 상태를 유지하고, 60초가 지난 응답은 적용하지 않습니다.
자동 화면 닫기·기한 만료 콜백·폼 교체 API는 아직 없습니다.
공식 Windows 베드락 앱의 실제 입장/렌더링은 여전히 미확인입니다.
Rust 플러그인은 신뢰된 실행 파일이며 WASI 샌드박스가 아닙니다.
사운드·모델 변환/API, 다른 플레이어 표시와 일반 게임 기능은 계속 구현 중입니다.

English: Adds API-v3 simple choice forms with native Bedrock menus and vanilla
Java dialogs. Validated selection/cancellation returns only to the owning plugin,
with v1/v2 executable compatibility retained. The unmodified Linux Java game
rendered the menu and a real click reached the Rust plugin. Independent clients
check both editions and isolation. General JSON-UI conversion and official Windows
Bedrock rendering remain unverified.
