# Java 26.3 shared-world preview

**확인된 문제:** 순정 Java 26.3으로 직접 시험한 결과 이전 게임 모드와 위치 확인 응답의
두 형식 오류 때문에 이 배포의 Java 경로는 입장하지 못합니다. 현재 소스에서 수정해
실제 평지·이동·마우스 편집을 확인했고 [Preview 9](https://github.com/SKYRPG8957/Sculith/releases/tag/v0.1.0-preview.9)로 배포했습니다.
[재현·수정·실제 게임 화면](../verification/2026-11-16-java26.3.md)을 참고하세요.
베드락 Interact/33 수정은 이 문제와 별개로 포함돼 있습니다.

Preview 7의 베드락 초기화 전 Interact/33 거부 수정은 그대로 포함합니다.
같은 Rust 프로세스와 월드 소유자에 Java 26.3 접속 경로를 추가했습니다.
공식 Minecraft 게임의 실제 입장·렌더링 성공은 아직 확인하지 못했습니다.

## 시험 방법

1. 기존 서버를 Ctrl+C로 종료하고 ZIP 전체를 **새 폴더**에 압축 해제하세요.
2. `diagnose.cmd`를 실행하세요. 서버 실행에 Rust·Python·Java 설치는 필요 없습니다.
3. 같은 PC의 베드락은 주소 `127.0.0.1`, 포트 `19132`로 접속합니다.
4. Java **26.3**은 멀티플레이 서버 주소에 `127.0.0.1:25565`를 입력합니다.
5. Ctrl+C로 종료하면 두 에디션이 공유하는 월드를 저장합니다.

새 기본 설정은 두 로컬 접속 경로를 켭니다. 기존 `sculith.toml`을 옮겼다면
Java 접속은 자동 활성화되지 않습니다. ZIP의 예제 설정에 있는 `[java]` 항목을
확인하세요. 기존 월드는 서버가 종료된 상태에서 `world` 폴더 전체를 옮겨 보존하세요.
NetherNet 서명 키는 개인 파일이며 배포 ZIP에 포함되지 않습니다.

## 변경 사항

- Java 26.3 / protocol 777 로그인과 알려진 순정 core 팩 협상, 레지스트리·태그,
  25청크 평지 전송, 초기화 확인과 세션 정리를 구현했습니다.
- 두 에디션의 이동·블록 입력은 기존의 같은 월드 소유자가 검사하고 승인합니다.
  별도 Java 서버나 두 번째 게임 시뮬레이션은 사용하지 않습니다.
- 초기화 전 입력, 재사용된 블록 요청 번호, 미확인 위치 교정과 클라이언트가
  주장하는 인벤토리는 월드 변경 권한으로 사용하지 않습니다.
- Java·베드락 RakNet·베드락 NetherNet 세 클라이언트의 양방향 블록 변경과
  최종 스냅샷·리비전·접속 종료 정리를 실제 소켓 테스트로 확인했습니다.

## 검증과 제한

Windows x64 [run 43772404771](https://github.com/SKYRPG8957/Sculith/actions/runs/43772404771),
정확한 소스 `441c438233931532d85bae86c2c0a59207fdeb34`에서 빌드했습니다.
워크스페이스·전송 코어 테스트, Clippy, 실제 EXE의 두 스모크 모드,
독립 Java·aiortc/OpenSSL·Go/Dragonfly 클라이언트 검사와 ZIP 실행기 검사가 통과했습니다.
독립 디코더는 각 에디션의 25청크에 있는 2,457,600개 블록 전체를 확인했습니다.
이는 공식 게임 화면의 입장·렌더링 검증을 대신하지 않습니다.

ZIP: **5,371,598 bytes**, SHA-256
`dbc08e5e7e29cddb999f18b42511d5da3f0ab8ce79b4885968f824814ffd9bff`.
빌드 출처, 체크섬, 의존성 라이선스와 Windows 시스템 DLL만 사용하는 EXE를 확인했습니다.

공개 배포는 [run 43773170515](https://github.com/SKYRPG8957/Sculith/actions/runs/43773170515)에서
동일한 검증 아티팩트를 사용했습니다. 인증 없는 새 HTTPS 다운로드의 체크섬과 메타데이터를 재확인했습니다.
Windows PowerShell 5.1 간편 설치, 두 실행기, 기존 설치 보존과 문서의 한 줄 설치 명령은
[run 43773340271](https://github.com/SKYRPG8957/Sculith/actions/runs/43773340271)에서 통과했습니다.

같은 PC의 명시적 오프라인 테스트 신원만 허용합니다. Java 온라인 인증과 다른
Java 버전은 미구현입니다. 다섯 기본 블록과 제한된 크리에이티브 건축만 지원하며,
다른 플레이어 표시·일반 인벤토리·생존/중력·주기적 저장은 아직 없습니다.
Java 조명은 수직 하늘빛만 계산합니다. 리소스팩 자동 배포·공유 모델/사운드/UI도
아직 구현 중입니다. 전체 크로스플레이나 완성된 콘텐츠 호환성을 뜻하지 않습니다.

English: Adds a loopback-only Java 26.3/protocol-777 adapter using the existing
Bedrock-native world owner, with negotiated vanilla registries, full chunks and
limited authoritative creative building. Retains Preview 7's Interact/33 fix.
Native Windows and independent protocol checks pass; official Minecraft entry
and rendering still need verification. No client mod or separate server is used.
